# geargina.com

Static site for Geargina Tan (Coach Gina). Plain HTML, CSS and JS. No build step, no CMS, no framework.

## The five rules

1. **Push to `main` is live.** Vercel auto-deploys. There is no staging step and no preview gate on `main`. Work on a branch, review the Vercel preview URL, then merge.
2. **Every committed file becomes a public URL.** `geargina.com/<path>` serves anything in the repo. Internal notes must be listed in `.vercelignore`, which currently excludes `CLAUDE.md`, `README.md`, `context/`, `.claude/` and `previews/`. After any push that touches those, confirm `curl -sI https://geargina.com/context/claims-and-proof.md` returns 404.
3. **The claims gate.** No number, price, statistic, testimonial or named client goes into the HTML unless `context/claims-and-proof.md` marks it CONFIRMED with a source. This rule exists because the site published 3 invented testimonials, a fabricated 5.0 star rating, and two unsourced statistics ("20+ Workshops delivered", "150+ Humans coached 1:1") under a heading reading "Receipts" for roughly 4 months. The earliest design mockup shows that block shipped as `0+ / 0+ / $0mil / 0%` placeholders, so the numbers were never data that went stale. They were empty slots filled with plausible-sounding values. A copy edit fixes the symptom. This gate fixes the cause.
4. **No AI-generated image may read as documentary evidence.** Illustration and brand art are fine. A generated room, audience, or event photo is not, and captioning one `// Workshop, SG` is how this site ended up implying workshops that never happened. Real photographs live in `assets/photos/`. Generated art lives in `assets/`. If a generated asset sits in a slot where a viewer would read it as proof, label it, exactly as `milo.png` already carries `// Generated by AI`.
5. **Prose bans, from the vault brand bible, and they apply here too.** No em-dashes, en-dashes or spaced-hyphen separators. No staccato triplets ("Not X. Not Y. Not Z."), and the ban extends to two-item negation lists and to any run of 3 similar-length short sentences. No AI-reflective filler. No banned verbs: unlocks, leverages, elevates, seamless, supercharge, harness, dive in, game-changer, delves, lands. Digits not words. Full list in `context/voice-and-brand.md`.

## Traps that will bite you

1. **The hero headline is rewritten by JS on every page load.** `apply()` sets `h1.headline.innerHTML` from the `HEADLINES` map. Edit the static `<h1>` **and** `HEADLINES.warm`, or your change reverts at runtime.
2. **Hero tile media is JS-controlled too.** `setHeroMedia()` replaces tile `a` from `HERO_SOURCES`. Changing the markup alone is not enough.
3. **Do not delete the `#testi` section.** `apply()` queries `[data-section="testimonials"]` with no null guard, so removing it throws and halts the rest of `apply()`, including the blog toggle. To hide it, set `TWEAK_DEFAULTS.testimonials: false`.
4. **`#offerings` and `#testi` ids are load-bearing.** The nav links to `#offerings` and the footer links to `#testi`, both from `site.js`.
5. **New `contact.html?topic=` values need a matching `<option>`** or the preselect silently no-ops.
6. **The FAQ JSON-LD is the copy answer engines quote.** Change it in the same commit as the visible copy, never later.
7. **Blog covers are forced to 16:9 with `object-fit:cover`.** Portrait source art must be composed onto a 16:9 canvas first or it gets cropped through the middle.
8. **`.article .body` has no `table` styles.** A post needing a table gets a scoped `<style>` in its own head, so one post does not force a cache-bust across every file.

## Cache busting

CSS and JS are versioned by hand with `?v=N`, currently appearing 26 times across the HTML. Bumping it means editing **every** file. Forgetting one serves stale CSS to returning visitors.

```
grep -rln 'site.css?v=' --include='*.html' .
```

Bump every hit in one commit. Do not migrate to `vercel.json` cache headers; it is not worth the complexity at this size.

## Structure decisions, so nobody "tidies" them later

- **Root HTML stays flat.** Moving pages breaks live URLs, canonicals, the sitemap and inbound links for no benefit at 12 pages.
- **`assets/photos/` is separate from `assets/` on purpose.** It makes the real-versus-generated distinction structural rather than something to remember.
