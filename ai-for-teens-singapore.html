🧠 What it would cover

What a large language model is and how it comes up with an answer. Where it is confidently wrong. How to use it as a tutor that asks questions back instead of an answer machine. How to get quizzed and tested by it using game mechanics. How to use it for research and projects without handing over the thinking.

🚫 What it is not

It is not a coding class, and homework does not come out the other end any faster. The thinking stays with them. They learn what the tool is doing under the answer, so they can tell when it is wrong. That part still works when the tools change.

What parents ask first

What age is this for?

13 to 18. Secondary school through JC and poly. If your child sits just outside that band, say so on the form. It changes how I'd group a room, and it is useful to know before I plan one.

Does my teenager need any technical background?

None. Every technical term would get a plain English definition and an example the first time it appears. They would need a laptop and an account you set up with them, because the tools I teach on all have age rules that put a parent in the loop. We would practise on a made-up assignment rather than live school work, since most schools now have their own rules about what can be pasted into an AI tool.

Is this teaching kids to cheat on their homework?

The opposite. Paste the question in, copy the answer out, is the habit this is built to break. They would learn what the model is doing when it answers and why it is confidently wrong sometimes, so they can use it to be quizzed and stretched instead of to skip the work.
